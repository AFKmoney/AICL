# Archived examples

This folder contains the 65 additional AICL programs that are not in the
[curated showcase](../showcase/). They are kept for reference, training
data generation, and historical interest. The AICL test suite does not
load these examples — they are not required for the compiler to function.

If you want to promote one of these into the showcase, open a PR that
moves it to `../showcase/` and updates `../showcase/README.md`.
